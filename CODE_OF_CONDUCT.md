# Código de conduta

Este projeto busca uma comunidade respeitosa, segura e útil.

## Comportamento esperado

- comunicar-se com respeito e objetividade;
- criticar ideias e mudanças, não pessoas;
- usar exemplos sintéticos ao relatar problemas;
- respeitar privacidade, autoria e limites profissionais;
- aceitar correções e decisões de moderação de boa-fé.

## Comportamento inaceitável

- assédio, discriminação, intimidação ou ataques pessoais;
- exposição de dados pessoais, conversas privadas ou credenciais;
- publicação de conteúdo malicioso ou instruções para enfraquecer guardrails;
- spam, promoção não solicitada ou interrupção deliberada das discussões.

## Relatos e aplicação

Não publique dados pessoais ou denúncias sensíveis em issues. Use um canal privado
indicado no perfil do mantenedor no GitHub. O mantenedor pode editar ou remover conteúdo,
encerrar discussões e restringir participantes quando necessário para proteger o projeto
e sua comunidade.

Este código se aplica a issues, pull requests, discussões e demais espaços oficiais do
projeto.
